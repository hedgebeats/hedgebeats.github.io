HEDGEBEATS — official artist website

HOW TO VIEW
Open index.html in your browser.

HOW TO PUBLISH FOR FREE (GitHub Pages)
1. Create a GitHub repository, e.g. hedgebeats-site.
2. Upload index.html, styles.css, script.js and the assets folder.
3. Go to Settings > Pages > Build and deployment, select Deploy from a branch, main / (root), Save.
4. GitHub will show your public site URL once deployed.

All links work without a server. Music links point to SoundCloud, and booking uses mailto.
The two original tracks are deliberately listed as private demos; no public demo URL is exposed.
For a custom domain, configure it under GitHub Pages settings after purchasing the domain.
